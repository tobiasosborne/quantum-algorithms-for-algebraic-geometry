# R11 thermal and CP-map definitions

2026-09-07. Definitions for independent tournament integration. The abstract
finite complexes and metric sampler explicitly use their supplied Hermitian
metrics rather than C1; their dimensions are independent of C2. The polynomial
emitter uses the existing Fock convention, including C3 conjugated annihilation.
Local alpha symbols are physical contraction/block normalization scales, an
explicit departure from C7. No input interface below is free merely because
its matrix has a geometric name.

## D-R11-HERMITIAN-COMPLEX

`C` is a finite graded Hermitian space, `d:C->C` has degree one and `d²=0`,
`Delta=d d†+d†d`, and `P` projects orthogonally onto `ker Delta`.
The permitted algebraic bath family has a Hamiltonian and finitely many jump
operators in the unital star algebra generated by `d,d†`. The Hamiltonian is
Hermitian. Its discrete version has Kraus operators in that algebra and
`sum_a K_a†K_a=1`. This is a restricted family, not all geometric bath models.

## D-R11-DUAL-NUMBER-FUSION

`A=C[e]/(e²)` has the declared orthonormal basis `(1,e)`. Multiplication from
`A tensor A` to `A` is

    mu=[[1,0,0,0],[0,1,1,0]],  K=mu/sqrt(2).

The complete instrument has successful Kraus map `K` and failure map
`sqrt(1-K†K)`, with orthogonal outcome flags and separate output spaces.
The tested source is two independent copies of one normalized pure vector
`psi=a|1>+b|e>`. The algebraic Frobenius pairing `epsilon(xy)`, where
`epsilon(1)=0,epsilon(e)=1`, is a distinct bilinear form; it is not this
Hilbert inner product.

## D-R11-METRIC-SAMPLER

Input is a finite list of nonzero vectors `s_i in C^q`, positive weights `w_i`,
a positive-definite Hermitian matrix `H`, and `c>=||C_s||`, where
`C_s=sum_i w_i s_i s_i†`. The proposed target matrix is

    T(H)=sum_i w_i s_i s_i†/(s_i†H s_i).

The initial state is `H/Tr(H)`. The measurement has Kraus operators
`M_i=sqrt(w_i/c)|i><s_i|` and failure complement `sqrt(1-C_s/c)`.
After outcome `i`, a separately charged preparation may produce
`v_i=H^(1/2)s_i/sqrt(s_i†H s_i)`. Reweighting uses
`a/(s_i†H s_i)` as the acceptance probability, with
`0<a<=min_i s_i†H s_i`. The raw ensemble includes outcome probabilities;
conditioning on acceptance is a separate normalization.

## D-R11-FINITE-CHANNEL

`E` is a completely positive trace-preserving linear map on the matrices of
a finite-dimensional Hilbert space. Spectral and Jordan statements refer to
this linear superoperator on all complex matrices. They do not identify its
fixed operator space with an arbitrary nonselfadjoint scheme algebra.

## D-THERMAL-SYZYGY-EMITTER

Use the existing graded polynomial ring in `n+1` variables and its Fock metric.
Given homogeneous generators `f_j` of degrees `m_j` and `d>=max_j m_j`, let

    F_d: direct-sum_j R_(d-m_j) -> R_d,  (u_j) -> sum_j f_j u_j.

The domain has positive dimension `L`, with Fock-orthonormal basis indexed by
`a=(j,g)`; here `g` is a normalized monomial of degree `d-m_j`. Let `p_a=g f_j`
and use the Fock-orthonormal basis also for the codomain matrix of `F_d`.
For `N>=d`, write `M_N=dim R_N` and

    V=sum_a |a> tensor a(p_a): R_N -> C^L tensor R_(N-d).

Choose a supplied positive `alpha` with `alpha²>=||V†V||`. The success block
is `V/alpha` and failure block is `sqrt(1-V†V/alpha²)`, with separate flags.
The input is the maximally mixed state `1_(R_N)/M_N`. The output bath state
means the unnormalized successful environment marginal. Its trace is the
success probability. If that trace is zero there is no normalized successful
bath state. A zero-eigenvalue syzygy is not sampled by measuring that state.

## D-THERMAL-SYZYGY-ABSORPTION

For the same `F_d`, choose positive `alpha_F>=||F_d||` and set `B=F_d/alpha_F`.
On `C^L_live direct-sum R_d_dead`, the sole jump is

    J=[[0,0],[B,0]],
    L(rho)=J rho J†-(J†J rho+rho J†J)/2.

There is no Hamiltonian. Initial state is the maximally mixed live sector;
the output at time `t` is the bit indicating that the state remains live.
A supplied normalized positive-eigenvalue bound is
`lambda_min^+(B†B)>=eta>0` when positive eigenvalues exist. The implementation
of this generator, preparation, elapsed time, repetitions and numerical
precision count. The model does not supply a thermal state or kernel projector.

## D-R11-MONOMIAL-FIRST-LOSS

`A=C[x_1,...,x_n]/J` is a nonzero finite-dimensional monomial quotient, with
its finite set of standard monomials as an orthonormal basis. Its dimension is
`D_A`. For every standard monomial `u` not divisible by `x_1`, its string has
length `lambda_u`, consisting of `u,x_1u,...,x_1^(lambda_u-1)u`.
The operator `S` moves to the next monomial in each string and kills its last
element. At each trial step, apply the survival map `S` or the failure map
`sqrt(1-S†S)`, record the outcome, and stop on failure. The source is the
maximally mixed state on `A`; `tau` is the first failure time, starting at one.
The same uniform-standard-monomial and successor interfaces are supplied to
the classical sampler. A Jordan-adapted basis for an arbitrary algebra is a
different, additionally charged input.

## D-R11-TRIPLE-QUOTIENT-QUERY

Input is a finite Hermitian associative differential graded algebra `(C,d,mu)`
with `d(xy)=d(x)y+(-1)^deg(x)x d(y)`, its multiplication matrix with bound
`alpha_mu>=||mu||`, and normalized harmonic vectors `a,b,c` all of degree one.
The products `ab,bc` are promised exact. Let `P` project onto `ker Delta`,
and let `P_2` be the degree-two harmonic
projector and `h=d†Delta^+`. Let `J_ind` be the linear subspace of harmonic
degree-two vectors representing `[a]H^1+H^1[c]`, and `Pi` the orthogonal
projector onto its orthogonal complement inside `range(P_2)`. The scalar is

    theta=||Pi(mu(h mu(a,b),c)+mu(a,h mu(b,c)))||.

The decision promise is `theta=0` or `theta>=gamma>0`. Access to the original
vectors, the Green operator, and the final quotient projector must each be
declared and charged; the definition does not construct those circuits.
This norm is fixed by the supplied metrics. No phase output is requested.
The nonzero spectral gap of `Delta` is bounded below by supplied `Delta_min>0`.
A regularized implementation uses `h_zeta=d†(Delta+zeta)^(-1)(1-P)` with
`0<zeta<=Delta_min`, and all error statements refer to this same scalar.

## D-R11-NONREDUCED-SYZYGY-CONTROL

Take the emitter and absorption definitions for the tuple `(z0²,z1²)` in
`n+1>=2` variables, `d>=4`, and ambient emitter degree `N=d`.
Use `alpha_F²=alpha²=d(d-1)`. For a degree-d exponent vector gamma, define
`s_gamma=gamma0(gamma0-1)+gamma1(gamma1-1)` and
`c_gamma=#{j in {0,1}:gamma_j>=2}`. A sampled domain column is a uniform pair
`(j,nu)` with j in {0,1} and nu a degree-(d-2) exponent vector; it gives
`gamma=nu+2e_j`, which necessarily has `c_gamma>=1`.
The classical control draws a bright branch with probability `1/c_gamma` and
otherwise a dark branch. A dark branch returns live; a bright branch returns
live with probability `exp(-t s_gamma/[d(d-1)])`. This describes its ideal
real-arithmetic law; sampling and scalar evaluation precision are charged in
an implemented approximate sampler. No quantum coefficient-list advantage is
asserted for this explicitly described complete-intersection family.
