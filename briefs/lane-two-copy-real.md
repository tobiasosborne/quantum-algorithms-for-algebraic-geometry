## The question (TJO, 2026-09-02)
"About real QM: do we simulate it via two copies to ensure real symmetry?" The real-variety lane showed there is no complex-linear projector onto K-fixed (real) vectors in ONE copy, K being antiunitary. The orchestrator's working answer: on TWO copies the antilinear condition becomes linear. For a vector p, realness up to a global phase is equivalent to |p^T p| = |p|^2, and the bilinear form p^T q is a linear functional on H tensor H via the pairing state |Phi> = sum_k |k>|k> (transpose trick (A x 1)|Phi> = (1 x A^T)|Phi>; SWAP^{T_2} = d |Phi><Phi|). So the two-copy observable Tr(rho rho^T) = |<psi-bar|psi>|^2 for pure states is a realness witness (this is the standard imaginarity measure: Hickey-Gour 2018, Wu et al PRL 126 090401 (2021), resource theory of imaginarity). For coherent states, <Phi|^{x N} (|p>^{x N} x |p>^{x N}) = (p^T p)^N, so the filter strength is exponential in N, and the postselection succeeds with probability (|p^T p|/|p|^2)^{2N}, which is 1 iff p is real up to phase. Pairwise projection onto |Phi> is a partial Bell measurement, which is native to linear optics with postselection.
