# New bounded construction: coherent extension correspondences

Read CLAUDE.md, PRD criterion 6 and D22--D24, and HANDOFF.md. Root owns
shared definitions, claims, tracking (`qaag-y71`) and commits. No additional
subagents. Write only `scouting/hall-extension-r7.md`.

The campaign has not derived an operation from Hall extension correspondences
on quiver-representation varieties. Construct one explicitly. A possible
starting point is coherent preparation of framed short exact sequences,
followed by interference between extension orders. This is a starting
suggestion, not a promised algorithm or a restriction to one Hall formula.

Select a finite-field quiver family and give matrices, dimensions, field bits,
input encoding and a geometric classical output. First derive the actual
amplitudes/Kraus operators or unitary on framed representations and flags.
Retain automorphism factors, flag registers and failure probabilities.
If forgetting a flag is many-to-one, compute its contraction norm rather
than treating classical pushforward as free coherent erasure.

Root's early classical attacks:

- Framed extension classes form explicit linear spaces in elementary cases;
  uniform random extension matrices are straightforward classical samples.
- A2 rank strata and matrix pencils have strong classical linear-algebra
  algorithms. Do not substitute an exponential explicit orbit list as baseline.
- General quiver-module isomorphism must not simply be called graph-
  isomorphism hard; charge an actual module-isomorphism algorithm or oracle.
- If interference requires a canonical middle-object label, the cost of
  computing it is part of the operation. Retained flags cannot be erased
  by declaring different presentations to represent the same moduli point.
- A Hall multiplication identity, finite character transform, standard
  quantum-group recoupling, ordinary LCU or a generic projector does not
  by itself satisfy D22. Require a materially different algorithmic operation.

Work from one explicit low-dimensional diagnostic toward a scalable family.
If the first operation reduces immediately to a known method or an efficient
classical sampler, state that calculation concisely and spend remaining
construction effort on a different operation, not a long no-go exposition.
Derive before targeted primary-source verification. Bound calculations;
no production checker is needed until a candidate merits one. Prefer a
compact memo of concrete equations, resource bounds and the exact surviving
lemma to a broad menu or another unsupported originality claim.
