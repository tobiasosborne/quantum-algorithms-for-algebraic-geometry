# Independent construction: geometric reconstruction

User authorizes subagents and relentless search across ALL algebraic geometry.
Read CLAUDE.md, PRD criteria 1--6/D22--D24, and HANDOFF for constraints and
completed dispositions. Do not repeat full familiarization or old probes.

Bounded task: derive one or two concrete quantum mechanisms for geometric
inference, interpolation, reconstruction, or another AG problem you judge better.
Choose a strongest explicit construction, derive its actual operation and
resource equation, then attack it. Send an early substantive formula. A menu of
objects or a new name for a known quantum algorithm is not a construction.

The result must potentially supply an original quantum mechanism, not merely a
new application/encoding/composition of Grover, QFT/HSP/DQI, generic spectral
filtering, LCU/invariant measurement, comparison/discrimination, or known
braid/Hecke/Baxterization algorithms. Basic gates are allowed. Do not refute
originality solely because a circuit can be compiled to a universal gate set.

State input encoding and output, an explicit nontrivial family, full resource
cost, strongest same-output classical attack, and the decisive missing lemma.
Do not substitute tomography for adaptive global single-original-copy
measurements in copy-access scalar tasks. No hidden component/root oracles.
Unknown metrics, closing gaps, and rare success must be charged. Prefer a
classical equation/circuit input if it supports an actual new operation.

Derive first; targeted primary-source browsing is only for verification of a
concrete idea. No web-led scouting. All computations bounded by timeout and one
BLAS thread. No subagents. Native collaboration replaces the old CLI workflow.

Writable file ONLY: scouting/reconstruction-mechanism-r5.md, roughly 250--350 lines.
Root owns shared registers and tracking (qaag-euy). No new claims are PROVED
before independent adversarial verification.
